# Changelog

## [1.0.0] - 2026-04-05

### Added
- Docker Compose setup with PostgreSQL, n8n, PostgREST, PGAdmin, Redis
- React Dashboard with Vite and TypeScript
- Invoice management (list, detail, approve/reject)
- Vendor management page
- Reports page with revenue charts and status breakdown
- Error logs monitoring
- CSV export for paid invoices
- n8n workflow integration for invoice processing
- PostgREST API integration for data fetching
- Responsive sidebar navigation
- Status filter and search functionality

### Infrastructure
- PostgreSQL 16 for primary data storage
- n8n for workflow automation
- PostgREST for auto-generated REST API
- PGAdmin for database administration
- Redis for caching support
- ngrok for external webhook access
