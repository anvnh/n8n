# Dashboard Styling Guide

## Design System

### Colors
- **Primary**: `#000000` (Black)
- **Background**: `#ffffff` / `#f4f4f5`
- **Text**: `#09090b` / `#3f3f46` / `#71717a`
- **Border**: `#e4e4e7`
- **Accent**: Monochrome palette

### Typography
- **Font**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700
- **Base size**: 16px

### Spacing
- Grid gap: 20px
- Card padding: 24px
- Section margin: 24px

### Border Radius
- Small: 6px
- Medium: 8px
- Large: 12px
- XL: 16px

### Components
- `.card` — Container with border and shadow
- `.badge` — Status indicators
- `.btn` — Buttons (primary, ghost, success, danger)
- `.table` — Data tables
- `.input` — Form inputs

### Design Principles
1. Minimal, monochrome aesthetic
2. Clean typography with Inter font
3. Subtle shadows and borders
4. Smooth transitions (0.3s cubic-bezier)
5. Consistent spacing system
